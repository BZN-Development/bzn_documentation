---
title: "Add-ons"
---

Add-ons are separate resources built on bzn's public API. They are optional: install the
ones you want, next to bzn_core.

| Add-on | What it does | Repository |
| --- | --- | --- |
| [bzn_multichar](/docs/addons/multichar) | character selection: a lineup scene where the camera moves in on the character you pick | [BZN-Development/bzn_multichar](https://github.com/BZN-Development/bzn_multichar) |
| [bzn_appearance](/docs/addons/appearance) | character creator; clothing saved by pack, so new packs never change outfits | [BZN-Development/bzn_appearance](https://github.com/BZN-Development/bzn_appearance) |
| [bzn_vehicledata](/docs/addons/vehicledata) | mileage and bodywork dents for owned vehicles | [BZN-Development/bzn_vehicledata](https://github.com/BZN-Development/bzn_vehicledata) |

Start add-ons after bzn_core (and ox_inventory):

```ini
ensure bzn_core
ensure ox_inventory
ensure bzn_appearance
ensure bzn_multichar
ensure bzn_vehicledata
```
