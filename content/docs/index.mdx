## How the pages are written [#how-the-pages-are-written]

Every function has the same four parts, in the same order:

1. **What it does**, in a sentence or two.
2. **The call**, with its arguments and their types.
3. **What it returns**, including every error string.
4. **An example** you can copy.

A `?` after a name means it can be left out or can be `nil`. Functions that can fail return
`false, '<error>'`: a short string for your code, not a text for players.
