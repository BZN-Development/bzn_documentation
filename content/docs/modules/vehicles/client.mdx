The server decides everything about vehicles. The client only does what only a client can
(read model data, apply a lock, settle a vehicle on its wheels, turn the radio off) and
there are no client functions to call. Read a vehicle's state from its **state bags**.

## State bags [#state-bags]

| State bag | Value | |
| --- | --- | --- |
| `bzn:vehicleId` | `integer` | the vehicle is owned; this is its id |
| `bzn:locked` | `boolean` | locked (set by the server; the owning client applies it) |

```lua
local vehicle = cache.vehicle or lib.getClosestVehicle(GetEntityCoords(cache.ped), 5.0)
if vehicle then
    local state = Entity(vehicle).state
    if state['bzn:vehicleId'] then
        print('owned vehicle', state['bzn:vehicleId'], state['bzn:locked'] and 'locked' or 'open')
    end
end
```

### Showing a lock icon [#showing-a-lock-icon]

```lua
AddStateBagChangeHandler('bzn:locked', '', function(bagName, _, locked)
    local entity = GetEntityFromStateBagName(bagName)
    if entity ~= 0 and entity == cache.vehicle then
        SendNUIMessage({ action = 'lock', locked = locked })
    end
end)
```

## Locking from a key UI [#locking-from-a-key-ui]

The client asks; the server checks access and locks:

```lua
-- client
lib.addKeybind({
    name = 'togglelock', description = 'Lock or unlock', defaultKey = 'U',
    onPressed = function()
        local vehicle = cache.vehicle or lib.getClosestVehicle(GetEntityCoords(cache.ped), 5.0)
        if vehicle then TriggerServerEvent('mykeys:toggle', VehToNet(vehicle)) end
    end,
})
```

```lua
-- server
RegisterNetEvent('mykeys:toggle', function(netId)
    local character = bzn.characters.get(source)
    if not character then return end
    local entity = NetworkGetEntityFromNetworkId(netId)
    local ok, lockedOrErr = bzn.vehicles.toggleLock(entity, { charId = character.id })
    TriggerClientEvent('ox_lib:notify', source, {
        description = not ok and 'No key' or lockedOrErr and 'Locked' or 'Unlocked',
    })
end)
```

## What the client does on its own [#what-the-client-does-on-its-own]

- **Radio off** when a vehicle spawns, and the first time the player gets in (config
  `radioOff`).
- **Getting out**: when the driver gets out of an owned vehicle (ox_lib cache), the client
  tells the server, which saves the vehicle (reading the values itself).
- **On the ground**: the client that owns a new vehicle settles it on its wheels.
