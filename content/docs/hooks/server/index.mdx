Every hook bzn fires on the server, one page per area. The tables below list all of them:
click a hook for what it means and an example.

How to listen, and the difference between the two kinds, is on the [Hooks](/docs/hooks) page.

## Reading a hook [#reading-a-hook]

Every hook is written the same way: its name, the arguments your function gets, when it fires, and an example.

```lua
bzn.hooks.on('groups:added', function(charId, name, grade, src)
    -- (charId, name, grade, src) is what the page lists after the name
end)
```

- A hook marked <Badge>before</Badge> runs **before** the thing happens and can stop it:
  return `false, 'reason'`. The others run after it has happened.
- `src` is the player's server id, or `nil` when the character is offline.
- `charId` is the character's id. Get the player from it with `bzn.characters.getSource(charId)`.
